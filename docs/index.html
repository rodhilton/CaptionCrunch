What it does

A small utility for the transcript-first workflow.

Caption Crunch is built for tabletop games, calls, streams, interviews, accessibility experiments, and any moment where you want captions without opening a full meeting app.

  • Choose a Mac input device in Settings.
  • Record, pause, resume, and stop live transcription.
  • Import common audio and video formats.
  • Save transcripts as plain text.
  • Use Copy All when a transcript is still updating.
  • Show configurable transparent overlay captions when minimized.

Transcript actions

Run your own commands on the transcript.

Add up to nine custom actions for AI summaries, cleanup scripts, publishing workflows, or anything else you can express as a shell command.

%fWrite transcript to a temporary text file and pass the file path.
%tPass the transcript text directly as a shell-quoted string.
%aPass the recording or imported media file path when available.

Routing app audio

Caption audio from other Mac apps.

To caption another app in realtime, route that app into a virtual input device and select it in Caption Crunch. Loopback by Rogue Amoeba is recommended for this kind of app-to-input routing.

Requirements

  • macOS 13 or newer
  • Apple Speech recognition availability for your locale
  • Microphone and speech recognition permission
